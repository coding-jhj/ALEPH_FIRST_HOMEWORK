IMPLEMENTATION

Android 스마트폰 카메라에서 직접 TFLite 기반 YOLO 모델을 실행합니다.

실제 TfliteYoloDetector에서는 GPU delegate를 우선 사용하고 실패하거나 지원되지 않는 경우 XNNPACK CPU로 전환합니다. YUV/RGBA 카메라 데이터를 모델 입력으로 변환하고 letterbox와 YOLO 후처리를 직접 수행합니다.

탐지 결과는 MvpPipeline에서 Kalman filter와 다단계 IoU association을 사용해 tracking합니다. 객체 종류·화면 중앙 위치·추정 거리·bounding box 크기를 바탕으로 위험도를 계산하고 NONE / SHORT / DOUBLE / URGENT 진동 패턴으로 변환합니다.

서버 측에는 detection, location, SSE event, tracker, DB와 route 관련 API가 분리되어 있습니다.

OPERATING STATES

HEALTHY

모델이 preload된 상태로 합성 요청을 정상 처리합니다.

DEGRADED

health 응답에 상태를 노출해 백엔드가 상황을 인지할 수 있게 합니다.

FALLBACK

timeout·모델 실패 시 대체 경로로 응답이 끊기지 않게 합니다.

TROUBLESHOOTING

  • 긴 TTS의 후반 음량 소실 → RMS 분석 → 문장 단위 합성/정규화
  • 긴 메시지 반복 fallback → 실제 원인은 150초 timeout → 300초로 수정
  • VRAM 이중 점유 → watchdog / pm2 운영 방식 정리
  • Windows CWD 상대경로 권한 오류 → 절대경로 기반으로 수정
